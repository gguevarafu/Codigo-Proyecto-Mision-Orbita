# Convenciones y estilos de programación

- Variables: se utiliza snake_case, escribiendo los nombres en minúsculas y separando las palabras con guion bajo. Ejemplo: `dias_viaje`.
- Constantes: se utiliza UPPER_SNAKE_CASE, escribiendo los nombres en mayúsculas y separando las palabras con guion bajo. Ejemplo: `COMBUSTIBLE_POR_DIA`.
- Tipos de datos: se utilizan enteros (`int`), decimales (`float`) y cadenas de texto (`str`).
- Condicionales: se utilizan las estructuras `if`, `elif` y `else`.
- Ciclos: se utilizan las estructuras `for` y `while`.
- Comentarios: se utilizan para explicar partes importantes del código.
- Indentación: se utilizan cuatro espacios para organizar las instrucciones.
